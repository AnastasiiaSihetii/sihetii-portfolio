# Контент внутрішніх сторінок

Текст живе тут, верстка — у `../_components`. Щоб змінити сторінку, майже завжди
достатньо правити файл у цій теці.

## Кейси й статті на блоках

`napa.ts` і `design-engineer-2026.tsx` описують сторінку плоским списком блоків
у тому порядку, в якому вони стоять на екрані:

```ts
blocks: [
  h2("overview", "Overview"),
  p("Перший абзац.", "Другий абзац."),
  fig("/case-studies/img/loops/02.jpg", "Опис для скрінрідера", "mid", 1600, 1020),
  h2("problem", "The problem"),
  ol("Пункт один.", "Пункт два."),
]
```

Конструктори лежать у `blocks.ts`:

| що це | як пишеться |
|---|---|
| заголовок розділу | `h2("id", "Текст")` |
| великий заголовок серії | `h2("id", "Текст", "chapter")` |
| крок усередині серії | `h2("id", "Текст", "step")` |
| підзаголовок | `h3("id", "Текст")` |
| абзаци | `p("перший", "другий", …)` — кожен аргумент окремий абзац |
| списки | `ol(...)` нумерований, `ul(...)` з тире |
| кадр | `fig(src, alt, size, width, height, caption?)` |
| стат-картки | `stats({ value: "50%", label: "…" }, …)` |
| цитата | `quote("Текст", "джерело")` |
| роздільник `· · ·` | `sep()` |

`size` у `fig` — це ширина кадру: `"mid"` (832px, одиничний скрін),
`"wide"` (1120px, на всю сітку), `"hero"` (те саме, але без верхнього відступу).
`width` і `height` обов'язкові: без них сторінка стрибає, поки вантажаться картинки.

Щоб переставити зображення перед заголовком — переставити два рядки.

Якщо в абзаці потрібне посилання, замість рядка пишеться JSX:

```tsx
p(<>Текст із <a href="https://…" target="_blank" rel="noopener">посиланням</a>.</>)
```

Такий файл має бути `.tsx`, а не `.ts`.

## Кейс дня народження

`birthday.ts` — не блоки, а іменовані списки (`days`, `stats`, `tech`, `tags`),
бо в цього кейсу власна верстка. Розмітка лежить поруч зі своїм CSS-модулем у
`../case-studies/birthday-website/`.

## Спільне

- `site.ts` — пошта й підпис автора.
- `other-work.ts` — реєстр сторінок для блоку «Інші роботи» в підвалі. Кожна
  сторінка показує всі записи, крім себе. Нова сторінка додається сюди один раз
  і з'являється в підвалі решти сама.

## Нова сторінка

1. Файл контенту в цій теці.
2. Роут: `src/app/<розділ>/<slug>/page.tsx`, який віддає контент у `EditorialPage`.
3. Запис в `other-work.ts`.
